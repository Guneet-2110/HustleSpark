# **App Name**: HustleSpark

## Core Features:

- AI Hustle Generation: Generate three personalized side hustle ideas based on user-provided skills and interests, using a self coded ai generator.
- Hustle Display: Present generated side hustle ideas with a catchy name and brief description on a clean dashboard. Without the premium the user will only be given 3 options without anything else.
- Premium Kit Access: Provide access to pre-made marketing kits including logos, flyers and social media templates for premium users.
- Magic Link Login: Implement a user-friendly email-based login system for simplified access to the application.
- Profile Management: Design a profile page for users to view saved hustles and manage their subscription status.
- Simulated Payments: Simulate payment functionality using a fake checkout system for testing purposes.
- Marketing Prompt Display: Show marketing prompts generated using the AI Hustle Generation Tool.

## Style Guidelines:

- Primary color: Vibrant purple (#9D4EDD) to reflect innovation and creativity.
- Background color: Dark grayish-purple (#1A1A2E), offering a modern and sleek look.
- Accent color: Soft pink (#EC4899) to add a touch of energy and highlight key interactive elements.
- Font: 'Inter', a sans-serif font known for its modern and readable design; appropriate for both headlines and body text.
- Centered layout with a minimal design aesthetic, inspired by Apple's design language.
- Employ subtle microanimations using Framer Motion to enhance user experience, like fade-ins and button hover effects.
- Use modern and simple icons to represent various actions and options within the app.
